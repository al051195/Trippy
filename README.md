# Trippy


A travel journal app for iOS. Import your photos and videos, organize them into moments, and turn the day into a story into a beautiful Liquid Glass journal.

## Features

- **Import** — pull photos and videos straight from your library and group them into moments automatically
- **On-device AI features** — title suggestions, search into your journal using natural search, draft a summary of your day generated from your titles and captions, yours ... And much more coming later in the year 
- **iPhone Duo Support** — Enjoy your best memories in a brand new, tailored design for the Duo

## Requirements

| | |
|---|---|
| Xcode | 27.1+ |
| iOS | 26.0+ |
| Swift | 6.4 |
| On-device AI features | iPhone 15 Pro or newer |

Trippy runs fully on any supported device — the AI features above simply stay hidden on older hardware.

## Getting started

```bash
git clone https://github.com/al051195/Trippy.git
cd Trippy
open Trippy.xcodeproj
```

Build and run on a simulator or device running iOS 26+.
